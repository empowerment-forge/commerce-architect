# Contributing to Commerce Architect

Commerce Architect is an early-stage open-source commerce platform stewarded by
Empowerment Forge. Thoughtful participation is welcome while the project
finalizes its contributor-rights model.

## Welcome Now

- Issues and bug reports
- Documentation feedback
- Architecture and design discussion
- Testing and evaluation
- Reproducible defect reports
- Feature proposals
- Forks and experimentation

Security reports must follow [`SECURITY.md`](SECURITY.md). Do not disclose
suspected vulnerabilities in a public issue.

## External Code Contributions

External pull requests containing code intended for merge into the official
repository are temporarily not being accepted. The project is finalizing a
Contributor License Agreement (CLA) and contribution-rights model so long-term
project stewardship, contributor rights, and possible future licensing options
are clear before external code is accepted.

No CLA exists yet, and its terms have not been selected. Appropriate legal
review is expected before adoption. Contributors will retain copyright in their
own contributions unless a future contributor agreement explicitly states
otherwise. The intended model is expected to grant Empowerment Forge sufficient
rights for project stewardship and possible future relicensing or commercial
licensing, but contributors should not infer legal terms that do not yet exist.

This temporary policy will be updated when the CLA and contribution process are
ready.

## Intended Development Workflow

When external code contributions open, the normal workflow is intended to be:

```text
fork
  ↓
branch
  ↓
pull request
  ↓
review
  ↓
CI
  ↓
maintainer merge
```

Until then, forks may be used for evaluation and experimentation, while issues
and design discussions remain the appropriate paths for proposing changes to
the official project.
