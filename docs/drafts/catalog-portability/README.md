# Catalog Portability draft material

These files are preserved draft/refinement material from the Catalog Portability
design and Hosting review. They are supporting material, not runtime authority
and not implementation authorization.

`docs/CATALOG_PORTABILITY.md` remains the separate committed current schema and
verified-media contract. The larger draft contains both current design/invariant
material and historical implementation-task instructions, including planned
T12–T17 work. Describing a later packet here does not mean that packet is
implemented or approved for execution.

The material has not been relocated or promoted into `docs/design/`. A later
review may split stable architecture/invariant material into `docs/design/` and
historical implementation prompts into `docs/ai-prompts/catalog-portability/`.
That disposition requires explicit review because the preserved files include
stale baseline claims and transient local-path references.
